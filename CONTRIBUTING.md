# Contributing

Thanks for looking. This project is small and the highest-value contributions are
probably not code.

## What helps most

**1. Reference breakdowns.** The skill gets better at direction the more worked examples
it can learn the *depth* from. If you analyse a promo film scene-by-scene — transitions,
camera moves, beats-per-second, typography technique, why each scene works — that is
directly useful. See [`docs/example-breakdown.md`](skills/promo-video/docs/example-breakdown.md)
for the expected depth, and add yours alongside it.

**2. Motion-language additions.** [`docs/motion-language.md`](skills/promo-video/docs/motion-language.md)
is the reusable grammar. If you know a technique that reads as premium across brands —
a transition, a composition rule, a timing heuristic — add it with a short "why it works".

**3. Scenes and components.** New orientation-aware scenes or shared components in
`template/src/` widen what the agent can assemble.

**4. Results.** Open an issue with your reference → your generated film. Real outputs are
the best evidence of what is working and what is not.

## Ground rules for the template

The template is a **reference implementation**, not a demo. Two rules keep it useful:

- **It must render on a fresh clone.** No asset may be referenced that is not committed.
  Placeholders are generated by `scripts/make_placeholders.py` — regenerate rather than
  hand-adding binaries.
- **It must stay brand-neutral.** No real product's name, copy, or screenshots. The
  shipped identity is a deliberately generic placeholder.

## Developing

```bash
cd skills/promo-video/template
npm install
npm run dev          # Remotion Studio
npm run typecheck    # tsc --noEmit
```

Before opening a PR:

```bash
npm run typecheck                                            # must pass
npx remotion still PromoVertical out/f.png --frame=1000      # must render
npx remotion still PromoStorePortrait out/s.png --frame=1000  # narrow frame, catches clipping
python3 -m py_compile scripts/*.py
```

If you change `T`/`dur` in `theme.ts`, update `DUR` in `scripts/build_audio.py` to match —
they are the same timeline and nothing checks this for you yet.

## Changing the skill itself

`SKILL.md` must stay valid against the [Agent Skills specification](https://agentskills.io/specification):
`name` matches the parent directory, `allowed-tools` is a **space-separated string**,
version info lives under `metadata`, and the body stays under 500 lines. Detailed material
belongs in `docs/` so it loads only on demand.
